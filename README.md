weirdest-job-title is a small program that writes the weirdest job title it can think of, as a single line: a Senior Vice President of Tupperware Lids.

## The title

The joke is built on one contrast: the most senior-sounding corporate rank against the least important object in the kitchen. A Senior Vice President is a real title, so the line reads like a genuine business card — until the job turns out to be lids. Everyone owns a drawer of containers with no matching lid, so the person doing this job is instantly picturable, solemnly managing the lids. At 40 characters it fits the 60-character limit with room to spare, and it reads in a single glance.

## Run it

```sh
python3 main.py
```

It writes the title to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
